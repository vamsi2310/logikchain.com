# Logikchain App Use Cases Traceability Matrix

This document provides the complete, authoritative specification of **all 67 Use Cases** across the Logikchain platform. Each use case is rigorously detailed with **WHO**, **WHAT**, **WHEN**, **WHY**, and **WHERE**, mapped 1:1 to agile User Stories, formal Work Items in `work-management/`, technical & operational Documentation, and Automated Test Suites (Bruno API tests & PWA Cloud E2E tests).

## 1. 5W Architectural Framework (Taxonomy)

Every use case in Logikchain adheres to the strict 5W operational taxonomy:

- **WHO (Primary Actor & Roles)**: The operating persona executing the journey (e.g. Rural Buyer, Village Merchant, Delivery Driver, Regional Supplier, Support Operator, Unauthenticated Citizen).
- **WHAT (Core Action & Capabilities)**: The concrete functionality executed, business logic processed, and state transitions recorded.
- **WHEN (Operational Trigger & Preconditions)**: The exact state prerequisite, schedule, or business event triggering the interaction.
- **WHY (Business Objective & Value Proposition)**: The core economic or logistical friction solved, KPI target, and fraud/regulatory protection achieved.
- **WHERE (Touchpoint, Screens & Channels)**: The physical location (Village shop, moving delivery truck, central warehouse, support console) and designated client UI screen ID(s) across Web PWA, Android Compose, and iOS SwiftUI.
