Critical Operational Gates & Circuit Breakers

Strict automated system blocks preventing financial losses and custody violations.

💰 Payout Custody Gate

A delivery driver cannot request or receive payout disbursements if there is an unresolved cash custody discrepancy.

BLOCK: payouts-service checks cash-service (discrepancies > 0) -> 403 CASH_DISCREPANCY_UNRESOLVED

Enforces: Zero cash leakage before driver wallet settlement.

🚚 Vehicle Departure Gate

A driver cannot start route navigation or stream GPS location until the warehouse loading manifest is sealed.

BLOCK: gigs-service checks pamphlet-service (status != 'sealed') -> 400 MANIFEST_UNSEALED

Enforces: Physical stock custody transfer verification before road transit.

📊 Merchant Credit Headroom Gate

A merchant cannot place a wholesale bulk order on credit unless available headroom exceeds order amount.

BLOCK: orders-service two-phase hold to credit-service -> 402 INSUFFICIENT_CREDIT_LIMIT

Enforces: Atomic headroom reservation with zero phantom debt.

🛡️ Zero-Trust Perimeter Gate

Microservices never accept un-attested public client traffic; all calls must carry App Check + Bearer tokens.

BLOCK: API Gateway validates Play Integrity / DeviceCheck / reCAPTCHA -> 401 APP_CHECK_FAILED

Enforces: Complete isolation of internal VPC and PostgreSQL databases.
